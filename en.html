CoSigning

A two-way translation platform between American Sign Language (ASL) and speech.

The problem

Deaf and hard-of-hearing people struggle to communicate day to day with people who don't know sign language.

The solution

Speech to sign: the site captures a spoken sentence, turns it into text, and plays a video for each sign in order. Sign to speech: a deep-learning Transformer model analyses webcam or uploaded video, extracting hand and body movement with MediaPipe and visual features with ViT, then turns the signs into an English sentence that is read aloud.

  • Python
  • PyTorch
  • Vision Transformer (ViT)
  • MediaPipe
  • OpenCV
  • FastAPI
  • JavaScript
  • Web Speech API
  • HTML
  • CSS

Employment Gap Study for Tech Graduates

A study of the employment gap among tech graduates, with its digital outputs.

The problem

Many tech graduates in Türkiye struggle to land their first job, and the gap between what they learned and what job ads actually ask for is unclear to them.

The solution

We analysed 216 tech job ads from Kariyer.net, Indeed and Eleman.net plus 405 graduate posts, then I built the Telegram bot “Graduate Compass AI”. It presents the findings with practical tools: a skills check, a job-ad explorer, a 30-day roadmap, a CV checker, a field comparison and “Ask the observatory” with sourced answers.

  • Python
  • python-telegram-bot
  • pandas
  • SQLite
  • Claude API
  • BM25

Library Management System

A desktop app for running a library: sign-in and registration, adding, editing and deleting books with cover images, issuing and returning books, and a chart of books by genre.

The problem

Many libraries track their books and loans by hand or in scattered spreadsheets, so it is hard to know which copies are available, who borrowed what, and when it is due back.

The solution

I built a C# desktop app with a SQLite database that brings it all together: sign-in accounts, book management with covers, issuing and returning books with stock updated automatically, and a chart of books by genre. I then rebuilt it as an interactive web version you can try right in the browser.

  • C#
  • Windows Forms
  • .NET Framework
  • SQLite
  • JavaScript (web version)
